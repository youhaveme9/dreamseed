# Security policy

## Supported versions

Security fixes are applied to the latest commit on the main branch until the first public release.

## Reporting

After the repository is published, report vulnerabilities through a private GitHub security advisory. Do not include secrets or private world data in a public issue.

DreamSeed accepts local MCP input as untrusted data. Reports involving validation bypasses, resource exhaustion, unsafe process handling, or arbitrary filesystem access are especially useful.
