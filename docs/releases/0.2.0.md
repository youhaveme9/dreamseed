# DreamSeed 0.2.0

DreamSeed 0.2.0 adds stronger official verification, Java 1.21.3, generated terrain inspection, and a local browser app. The default remains a local Java Edition seed finder with no model API key requirement.

## What is new

Java 1.21.1 and 1.21.3 use a shared pinned version registry. All ten structure targets have official start fixtures for each version. Exact candidate verification rechecks selected biome witnesses, counts, radii, spatial pairs, and scores with Minecraft itself.

Structure48 sampling reuses placement state across full world seed cohorts. The optional native Metal filter handles placement only and is not enabled as a search backend. Its local benchmark was slower than CPU for the measured small workload.

Generated terrain inspection reads actual saved heightmaps, surface states, and biomes, with separate command controls. Numeric preference scores and sampled terrain classifiers are transparent and experimental. SVG heightmaps and OBJ surfaces are interpolated previews, not complete voxel scenes.

Igloo verification can compare all non marker template block states from the installed pinned official server. Other structure block comparisons, entity contents, and subjective scenic guarantees remain unsupported.

The standalone browser app stays on loopback with session and origin checks. Optional HTTP MCP requires one configured owner, signed tokens from an external OAuth provider, and a separately operated TLS proxy. The default transport remains stdio with no credentials.

## Installation and upgrade

Start with the [README quick start](https://github.com/youhaveme9/dreamseed/blob/v0.2.0/README.md#quick-start), or choose a validated native archive and the Python wheel from this release. The complete source archive includes the Claude plugin, skill, tests, and examples. `SHA256SUMS` and `release-manifest.json` describe the published assets and their actual platforms.

After upgrading, restart your MCP server or AI client to discover all eleven tools. Existing completed jobs remain inspectable. Active jobs are not automatically resumed. Install each optional official Minecraft version separately after reading and accepting its EULA.

## Validation

Release gates cover the native engine, sanitizers, Python schemas and jobs, actual MCP sessions, authenticated HTTP, browser API and client behavior, source rebuilds, installed wheel smoke tests, and package checksums. Linux and macOS bundles must pass their own platform builds before publication. CI does not download Minecraft or accept its EULA; official integration skips there are not represented as official verification.

The final local gate passed 120 Python tests with real Minecraft integration enabled and no skips, plus native CTest, address and undefined behavior sanitizers, wheel construction, and strict Claude plugin validation.

The [local validation record](https://github.com/youhaveme9/dreamseed/blob/v0.2.0/docs/validation/2026-10-21.md) documents actual official server checks for both supported versions, all ten structure starts, exact candidate constraints, igloo template states, generated terrain, and fluid safety controls. It also includes a real discovered and officially verified seed.

## Known limits

All proximity measurements use explicit coordinates, defaulting to the world origin, not actual world spawn. Native results remain predictions until upgraded by the applicable official checks. Generated start metadata does not prove every structure block. Exact block comparisons are limited to declared igloo template states.

Terrain classification and numeric similarity are experimental sampled measurements, not semantic terrain guarantees or objective beauty. Surface meshes are not full voxel renders. Metal filtering is placement only and was slower than CPU in the measured local workload.

Browser API and client tests passed, but visual review was unavailable because headless Chrome could not initialize on the local validation host. The browser app is local only. Optional HTTP supports one configured owner; this release does not deploy a public service or include a TLS proxy or OAuth provider.

Bedrock, other Java versions, world spawn constraints, and broader structure block validation remain unsupported. A bounded search finding no result never proves global absence.

See the [roadmap](https://github.com/youhaveme9/dreamseed/blob/v0.2.0/docs/roadmap.md) for exact milestone status and [release procedure](https://github.com/youhaveme9/dreamseed/blob/v0.2.0/docs/releasing.md) for packaging. Existing 0.1.0 assets remain unchanged.
