# DreamSeed 0.1.0

DreamSeed finds Minecraft Java 1.21.1 seeds using a native Cubiomes search engine and a local MCP server. An AI client translates your description into search constraints. All world generation computations run locally. No OpenAI or Anthropic API key is required.

## Included

1. Native CLI and nine MCP tools for search, status, results, cancellation, inspection, comparison, capabilities, official verification, and biome map rendering.
2. Exact biome constraints, sampled biome proximity, ten structure types, structure counts, spatial relations, and deterministic distance scoring.
3. Bounded sequential or sampled searches with configurable time, candidates, workers, and results.
4. Durable local job records and result recovery after a server restart.
5. Optional official Minecraft locate verification for villages, pillager outposts, and supported biomes, with generated surface and teleport clearance checks.
6. Structured biome maps and static SVG maps with separate prediction and verification markers.
7. Claude Code plugin and reusable seed finding skill.
8. Source and native archives, a Python wheel, SHA256 checksums, installation checks, and reproducible tests.

## Verification example

The official Minecraft Java 1.21.1 server locates a plains village at X 48, Z 16 and a pillager outpost at X 256, Z 256 for seed `-7333811035076652275`. Generated surface checks report Y 91 and Y 118 respectively, with clear space and ground support at both points. The same seed also locates plains, cherry grove, and jagged peaks near the origin.

The official integration test also checks an ocean point at X 1440, Z 288, reports water at surface Y 63, and rejects it as a teleport target.

## Limitations

The target is Java 1.21.1 only. Search results are Cubiomes predictions. Official verification is optional and has a narrower structure target list than the search engine. `minecraft_located` records the official server's locate answer; it does not claim a block accurate entrance or complete structure start validation.

Biome proximity samples a grid and may miss features between samples. Distances use horizontal Euclidean blocks from an explicit reference, defaulting to world origin. Actual world spawn is not calculated.

Surface checks require clear feet and head space and exclude water, lava, air, and powder snow as support. They do not guarantee protection from every terrain or gameplay hazard. SVG output is a sampled biome map. Terrain screenshots, scenic scoring, Bedrock, remote hosting, and other Java versions remain future work.

A bounded search finding no match only exhausts its stated budget. Active jobs recovered after a server restart become interrupted and do not resume automatically.
